# nas-hdd-installation-and-raid-configuration
This activity documents the installation of two 12TB hard disk drives (HDDs) into a Network Attached Storage (NAS) device and the reconfiguration of the storage array from RAID 1 to RAID 5.

## Project Objectives
- Install two 12TB hard drives.
- Change RAID 1 to RAID 5.
- Verify drive detection and storage status.
- Document installation and configuration process.

## Tasks Performed
- RAID configuration from RAID 1 to RAID 5.
  ![RAID configuration](images/raid-configuration-before.jpg)
- Installation of two 12TB HDDs in Bays 3 and 4.
  ![RAID configuration](images/raid-configuration-before.jpg)
- Verification of installed drives through the NAS management interface.
- Documentation of the storage configuration process.

## Hardware
- Device: Synology Network Attached Storage (NAS)
- Storage Drives: 2 × 12TB HDDs
- Drive Bays: Bays 3 and 4
- RAID Configuration: RAID 1 to RAID 5 

## Skills Demonstrated
- NAS Administration
- RAID Configuration
- Hardware Installation
- Storage Management
- Technical Documentation
